Fractal-Guided Image Filtering with Adaptive Tuning
for Single Image Detail Enhancement (FGIF)
=================================================

This project provides a MATLAB implementation of the proposed
Fractal-Guided Image Filtering with Adaptive Tuning (FGIF) method
for single image detail enhancement.


1. Environment Requirements
---------------------------
- MATLAB R2018a or later
- Image Processing Toolbox

No third-party libraries or external dependencies are required.


2. Directory Structure
----------------------
FGIF/
│
├── demoforfgif.m        % Main demo script (entry point)
├── data/               % Input demonstration images
└── result/             % Pre-generated demonstration results (for reference)


3. One-Click Running Instructions
---------------------------------
Step 1:
Open MATLAB and set the current working directory to the project root.

Step 2:
Run the demo script:

    demoforfgif

No additional parameter configuration is required.


4. Input and Output Description
-------------------------------
Input:
- Test images are loaded from the "data" folder.
- Supported image formats include .png, .jpg, and .bmp.

Output:
- After processing, the input image and the enhanced image are
  displayed for visual comparison.
- The "result" folder only provides pre-generated results for reference.


5. Notes
--------
- This implementation is intended for research and academic use.
- Users may modify parameters in "demoforfgif.m" for customized experiments.
